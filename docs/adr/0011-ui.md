# ADR-0011: UI - React via Bun HTML imports
Status: Accepted 2026-10-17 · Roadmap: D11

## Context
A dashboard is needed in M2; the API already runs on Bun.

## Decision
React served through Bun HTML imports. No Next.js and no separate frontend build tool.

## Consequences
- One runtime and one deploy artifact for API and UI.
- No SSR or file-based routing; not needed for an authenticated internal tool.
- Revisit in UI-1 before building on it.
