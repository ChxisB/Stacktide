# 27 Variable folders - Tasks

Gate for every task, from the repo root: `bunx biome format --write <touched folders>`, `bunx biome check .`, `bun run typecheck`, then the suites of the folders touched (`bun test --env-file=.env.example packages apps/api apps/cli`, `cd apps/web && bun test --env-file=../../.env.example`). Tests need Postgres on `localhost:5433` (`bun run dev:db`). Web tasks also run `bun run e2e`. Nothing here touches a real GitLab or cloud account.

**Rule for every task: with no folder created, every existing test passes unchanged.** The root is the old world; a test that has to change is a finding, written in LOG.md, not an edit made quietly.

**Cuts.** FLD-1 to FLD-10 make folders usable through the model, API, sync and CLI. FLD-11 to FLD-15 are the page. FLD-16 delivers. You can approve the first cut alone.
