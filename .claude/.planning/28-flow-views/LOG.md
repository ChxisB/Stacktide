## 2026-10-20 - FLW-2 Graph layout as data
- `apps/web/src/run-graph-layout.ts` (new, no React, no DOM): `layout(stacks)` returns `{ boxes, edges, width, height }`. Constants `BOX` (176 by 52), `GAP` (64 by 16) and `PAD` (12). A wave is a column (the waves present are numbered 0.. in order, so an unexpected gap in the numbers leaves no empty column), the names of a column are rows in sorted order, a line runs from the right side of the stack waited for to the left side of the one waiting (a cubic curve).
