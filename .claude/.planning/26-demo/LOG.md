## 2026-10-20 - DEMO-4 Screenshots
- **Built:** `bun run demo:shots` runs `demo/shots.e2e.ts` through its own Playwright config, which starts the demo server (port 3210, `DEMO_PORT` moves it). It signs in with the demo link, visits the ten pages in dark and light at 1280 wide and writes `apps/web/demo/shots/<page>-<theme>.png` (git-ignored, kept out of the image). It fails on: the error boundary, a sideways scroll, a page error, a console error, a response of 400 or more, or text still reading "Loading...". It sets reduced motion so the sidebar is not caught mid-transition, gives the State page the seeded stack `network`, and sizes the viewport to the page so the one-screen-high sidebar reaches the bottom of the picture.
- **Why a Playwright test and not a `shots.ts` script:** the repo already has Playwright (`apps/web/e2e`) with a webServer and `expect`; a script would have rebuilt both. The task text is updated.
- **One allowed 404:** an organization with no single sign-on answers `GET /organizations/:id/sso` with 404, which the Settings page reads as "none". The script ignores that one response (404 and a path ending in `/sso`) and nothing else. Seeding an identity provider to avoid it would be an auth-model change, a human gate, for no gain.
- **Found by looking at the first twenty pictures** (the run was green before): they went to `apps/web/undefined/` because `import.meta.dir` does not exist under Playwright's Node runner (now the project's test directory); State was empty (no stack typed); Pipeline said "Loading pipeline..."; the active sidebar item was mid-transition; the sidebar stopped at 800 px on tall pages.

The connection reads `http://127.0.0.1:<port>` (the mock), which the doc now says.

One thing to know, written into the doc's Safety section: cookies ignore the port, so opening the sign-in link replaces the `orch_session` cookie of another copy of the platform on `127.0.0.1`. A web page the viewer visits can make their browser hit the sign-in port, which plants a demo session and signs them out of such a copy; it gains nothing, because the data is invented.
