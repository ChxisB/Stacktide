# 30 Variables screen - Tasks

Gate for every task, from the repo root: `bunx biome format --write apps/web`, `bunx biome check .`, `bun run typecheck`, `cd apps/web && bun test --env-file=../../.env.example`, `bun run e2e`. Tests need Postgres on `localhost:5433`. Pictures: `bun run demo:shots` and the demo tests (`cd apps/web && bun test --env-file=../../.env.example demo`). Nothing here changes the API, the database or a guard, and nothing touches a real GitLab or cloud account.

**Rule for every task: existing tests pass unchanged, or the change is a named finding.** A control that stays on screen keeps its accessible name (an icon button gets the old text as `aria-label` and `title`). A control that moves into a menu or a drawer changes how its tests reach it: write each such test in LOG.md as a finding, keep the assertion as strong, never delete or skip one. Every new CSS class gets a rule in `apps/web/src/styles.test.ts`. A layout fault is found by looking at the picture, so every picture is read, not only asserted.

**Cuts.** A (VUI-1 to VUI-5) the face of the Secrets view. B (VUI-6, VUI-7, VUI-13, VUI-8, VUI-14) drawers and menus. ### VUI-19 - Alignment and hover across the platform  `[x]` M - deps: VUI-18
