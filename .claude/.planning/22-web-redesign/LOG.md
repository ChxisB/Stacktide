## 2026-10-20 - RDS-1 Carebell tokens and the forced-theme sets
- `styles.css`: Carebell values under the existing token names; new tokens (`--raised --line-strong --field-line --accent... --action --on-action --active --idle --hl` and the five tints); dark written for a dark system (guarded by `:root:not([data-theme="light"])`) and for `:root[data-theme="dark"]`; `:root[data-theme="light"]` sets `color-scheme` only (the guard is what lets a forced light beat a dark system).
- Text-safe status values are shared by glyph and word, so light `--ok` is `#1d6b3a`, not the design's `#2da860`, and light `--active` is `#0b6f61`, not `#1fa594` (both fail 4.5:1 as text).
- `styles.test.ts`: dark and forced-dark regexes read the new selectors; new test pins the two dark sets equal; 14 new contrast pairs (text on each tint, status word on its own tint, accent on page, action).
- Gate: typecheck, lint, 316 web tests pass (315 + 1).

## 2026-10-20 - RDS-2 Self-hosted fonts
- New dependencies (one line each): `@fontsource-variable/plus-jakarta-sans@5.3.0` and `@fontsource-variable/jetbrains-mono@5.3.0` - the design's two typefaces as OFL variable woff2 files, so the page makes no third-party request.
- Only the Latin subset is declared, in two `@font-face` rules that point at the package files; the packages' own CSS inlines nine subsets (205 KB of CSS) and these two cost 98 KB. A glyph outside Latin falls back to the system font.
- Bun's bundler inlines the woff2 files into the CSS as `data:` URIs instead of emitting them as files, so the task's "emits the font files" became "the build carries the fonts". A future CSP would need `font-src data:`.
- Gate: typecheck, lint, 316 web tests pass.
